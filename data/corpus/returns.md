# Return Process

To return an item, start a return request in the order history page and print the prepaid return label. Items must be shipped back within 14 days of starting the request. A restocking fee of 15 percent applies to opened electronics. Returns are inspected at the warehouse before a refund is issued. Damaged items must be reported within 48 hours of delivery. Customers are responsible for return shipping costs unless the item is faulty.
