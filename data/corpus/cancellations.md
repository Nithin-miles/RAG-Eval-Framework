# Order Cancellation

Orders can be cancelled while the status is still Processing. Once an order has shipped, it cannot be cancelled and the customer must wait for delivery. Shipped orders can be returned using the standard return process. Cancellation of a Processing order refunds the full amount within 3 business days. Custom or personalised items cannot be cancelled after 24 hours because production has already started. To cancel, open the order in the account and select Cancel Order.
